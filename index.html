API 문서

v1

WinProb REST API — 상황 기반 승률 예측을 어디서든 호출하세요. (데모 명세)

개요 & 인증

Base URL: https://api.winprob.ncloud.app · 모든 요청은 API Key 헤더가 필요합니다.

Authorization: Bearer YOUR_API_KEY Content-Type: application/json

엔드포인트

POST/v1/winprob

현재 경기 상황과 팀 변수로 승리 확률을 계산합니다.

// Request { "home": { "obp": 0.360, "whip": 1.30 }, "away": { "obp": 0.355, "whip": 1.38 }, "situation": { "inning": 9, "half": "bottom", "outs": 2, "bases": [1,0,1], "score": { "away": 3, "home": 2 } }, "options": { "iterations": 5000 } }
// 200 OK { "win_prob": { "away": 0.612, "home": 0.388 }, "expected_score": { "away": 3.4, "home": 3.1 }, "at_bat": { "on_base": 0.318, "hit": 0.214, "walk": 0.095 } }
GET/v1/teams

분석 가능한 KBO 팀 목록과 시즌 성적을 반환합니다.

// 200 OK [ { "code": "OB", "name": "두산", "obp": 0.355, "whip": 1.38 }, ... ]
GET/v1/teams/{code}

특정 팀의 상세 성적을 반환합니다. 예: /v1/teams/LG
